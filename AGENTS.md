# Rename Field tutorial

Build and deploy only this public educational application. GitHub Pages destination: https://technoetic.github.io/rename-field-tutorial/. No Sites hosting or source copies to Sites. Never access credentials, private vault material, or other projects' user data.

Keep native ES modules by responsibility, class-based screens/services, layered CSS, asynchronous loading with stale-response protection, hash deep links, real missing-asset 404s, and build-identity-based automatic full-document update on the next clean navigation. Protect drafts and saves. No added runtime dependency or service worker.

Use the existing selected infrastructure's public behavior. Keep all tutorial examples fictional and all user rendering text-safe. No eval of user input. Learning content concerns object field names, not Rename Variable, Split Variable, SQL schema changes, or the claim that a label alone changes a data key.

Only Aside CLI for browser automation. On Windows run the environment's Aside startup helper, then invoke a Bash script file; the Bash file calls aside repl with JS file contents. No Playwright packages. Public pages may be inspected. No site submission beyond explicitly authorized GitHub deployment.

Use Node built-in test runner. Write meaningful failing tests for new model and screen behavior before implementing it. Retain tests for inherited update, storage, HTTP and asset behavior. Each implementer owns only the files assigned by root and must not commit or push until root integrates. Main is a new, isolated repository for the user-authorized app.
